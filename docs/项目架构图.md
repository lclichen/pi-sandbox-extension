# AgentSandbox 项目架构图

> 初版源：企业产品评估报告（2026-08-07）。随实现演进持续更新；当前态以本图 + `AGENTS.md` 为准。

## 整体架构（Mermaid）

```mermaid
flowchart TB
    subgraph Client["客户端层"]
        PI["pi CLI 扩展<br/>pi-sandbox-extension/"]
        WEB["Web 管理台<br/>React SPA"]
    end

    subgraph Platform["平台层 · sandbox-platform (Node.js + Express)"]
        direction TB
        AUTH["Auth 中间件<br/>JWT + API Key"]
        ROUTES["Routes<br/>auth/users/quotas/images/<br/>containers/tools/admin/workspaces"]
        SERVICES["Services<br/>user/quota/image/container/<br/>workspace/log/tools/auth/apikey"]
        DAL["自建 DAL<br/>Sqlite / Postgres 双实现"]
        EXECUTOR["执行器抽象<br/>SandboxExecutor 接口"]
        AUDIT["Audit 中间件<br/>operation_logs"]
    end

    subgraph Runtime["运行时层"]
        direction LR
        MOCK["MockExecutor<br/>本地目录 (dev/win32)"]
        SSH["SshExecutor<br/>node-ssh → apptainer (生产)"]
        CLI["ApptainerCliExecutor<br/>直接 spawn (保底)"]
    end

    subgraph Host["Apptainer 宿主"]
        direction TB
        INST["Apptainer 实例<br/>instance start"]
        OV["持久化 Overlay<br/>ext3 / 目录"]
        SIF["SIF 基础镜像<br/>squashfs 只读"]
        SNAP["快照目录<br/>overlay 副本"]
        WS["用户工作区种子<br/>WORKSPACE_BASE_DIR"]
    end

    PI -- "HTTPS REST + JWT/API Key<br/>read/write/bash/grep/find/ls" --> AUTH
    WEB -- "同源 HTTPS" --> AUTH
    AUTH --> ROUTES
    ROUTES --> SERVICES
    ROUTES -- "写操作自动落盘" --> AUDIT
    SERVICES --> DAL
    SERVICES -- "getExecutorFromReq" --> EXECUTOR
    EXECUTOR -.->|"工厂 fallback"| MOCK
    EXECUTOR -.->|"生产优先"| SSH
    EXECUTOR -.->|"保底"| CLI
    SSH --> INST
    CLI --> INST
    INST --> OV
    INST --> SIF
    OV -.->|"快照 = cp overlay"| SNAP
    WS -.->|"workspaceId 播种 /workspace"| INST
```

**图例**：快照（Stop-Then-Copy）与工作区种子均已实现（见 `container.service.ts` / `workspace.service.ts`）。

## 核心数据流

```
pi 扩展(本地)  ──HTTPS REST + JWT/API-key──►  平台(Express)  ──SSH / apptainer CLI──►  Apptainer 容器
read/write/bash/grep/find/ls                 控制平面 + 执行器         实例 + 持久化覆盖层
                       ◄──SSE 流(bash)──
Web 管理台(浏览器) ──同源 HTTPS──► 平台(同上)
```

## 分层职责

| 层 | 职责 | 关键文件 |
|---|---|---|
| 客户端 | pi 工具覆盖 + 斜杠命令；React 管理台 | `pi-sandbox-extension/`, `sandbox-platform/web/` |
| 路由 | 参数校验（zod）+ 鉴权 + 调 service + 返回 JSON | `src/routes/*.routes.ts` |
| 服务 | 业务逻辑，工厂函数 `createXxxService(db)` | `src/services/*.service.ts` |
| 执行器抽象 | 平台 ↔ 容器运行时边界，三实现 + 工厂 fallback | `src/executors/types.ts` + 三实现 |
| DAL | 屏蔽 sqlite/pg 方言差异，`?` 占位符统一 | `src/db/driver.ts` |
| 宿主 | Apptainer 实例 + overlay + 快照 + 工作区种子 | 远端文件系统 |

## 容器生命周期状态

```mermaid
stateDiagram-v2
    [*] --> creating: POST /containers
    creating --> running: executor.create 成功
    creating --> error: executor.create 抛错
    running --> stopped: POST /:id/stop
    stopped --> running: POST /:id/start
    running --> stopped: snapshot (Stop-Then-Copy)
    note right of running
        快照采用 Stop-Then-Copy：先 stop 实例
        quiesce overlay，cp 出副本，再恢复运行
        （container.service.ts snapshot 流程）
    end note
    stopped --> [*]: DELETE /:id (destroy)
    error --> [*]: DELETE /:id
```
